# Account Dashboard Basics

Your Account Dashboard is the operational home for your migration projects. It centralizes the key actions you need during execution: creating and managing migrations, configuring connections, monitoring progress, accessing any eligible modules, tracking billing artifacts, and working with support.

#### Core areas you will use most often

**1) Account Overview**\
A quick status view of your recent activity and migration state. Use it to confirm whether runs have completed and whether any support items are still open.

**2) My Licenses / My Services**\
Your entitlement view. This is the reference point for what services or packages are active on your account and what they allow you to run or access.

**3) Migration Tool Management**\
Your execution console. This is where you:

* Create a migration for a specific Source to Target pair
* Provide connection details (API, KitConnect, or file-based inputs)
* Select the data scope and any migration options
* Start a Demo, Full, or Recent Data Migration
* Monitor progress and review migration outputs where available

**4) Billing & Invoices**\
Used for payment records and invoice downloads. Finance teams typically rely on this area for procurement documentation.

**5) My Tickets**\
Your support workspace for structured troubleshooting and follow-up. Use tickets when you need:

* Help resolving connection issues
* Help interpreting missing or mismatched data
* Clarification on migration behavior and validation outcomes
* Technical confirmation before go-live

#### A typical “during-use” dashboard workflow

1. Create or open a migration project in Migration Tool Management
2. Run a Demo Migration
3. Review results and adjust configuration if needed
4. Run the Full Migration
5. Complete validation checks
6. Run Recent Data Migration before launch
7. Use My Tickets if any issue blocks execution or sign-off
